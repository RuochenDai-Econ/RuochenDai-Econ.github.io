# Homepage publication rules

## CER Open Data: descriptions and links only

- Never upload research data to this homepage: public or private, raw or cleaned, anonymized, aggregated or sample data. Never upload materials privately supplied by authors to the editor, including data, replication archives, attachments and correspondence.
- CER Open Data may publish dataset names, producers/providers, brief descriptions of the information covered, access conditions, article DOIs and replication-package DOIs. Link to original providers and public Dataverse deposits; do not mirror their files.
- Base descriptions only on publicly released READMEs or official public documentation. Do not expose details learned only from private materials or infer undisclosed provider identities. Keep English primary and Chinese secondary.
- Do not upload author README files, research programs, logs, internal review reports, sample/observation-count attachments, credentials or data screenshots. Research records must not be embedded in HTML, JSON, text, images or code.
- Website HTML, styles and rendering code may be updated to support the index, but must contain no research records. The index JSON contains descriptive and bibliographic metadata only.
- Use an explicit publication file allowlist. Review every changed file and its contents before publication, then verify the actual remote commit against the allowlist. Never upload local research/manuscript folders wholesale. Keep audit evidence outside this public repository.
- Authorization to publish the homepage does not authorize uploading research data or privately supplied materials.
